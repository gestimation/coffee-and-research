Aalen-Johansen法　Aalen-Johansen method
競合リスク解析において、累積発生曲線を推定する方法。

アウトカム　outcome
研究で観測したい結果や治療の成績のこと。死亡、再発、血圧、患者満足度などがアウトカムの例。アウトカムをどう定義するかによって、必要なデータや解析方法が変わる。

αエラー　alpha error
治療が本当は効かないのに有効と考えたり、関連がないのにあると判断してしまったりする類の誤り。偽陽性といってもよい。p値などを用いて5%以下に抑えることが、医学研究の慣習になっている。

イベント　event
生存時間解析において、アウトカムとして設定した出来事のこと。

一般化線型モデル　generalized linear model
抽象的なデータの見方を「モデル」と本書では呼んでいる。一般化線型モデルは確率モデルの一種で、回帰分析、分散分析、ロジスティック回帰などの統計手法の総称。「一般化」という名称は、古典的な回帰分析を、さまざまな確率分布を扱えるように拡張したことからきている。交絡調整や予測など多岐にわたる目的で用いられる（田中2022、要引用）。
このモデルを使用するときには、主に3つのことを指定する。第一に、アウトカムの型に対応する確率分布である。たとえば連続データでは正規分布、2値データでは2項分布、計数データではPoisson分布を用いることが多い。第二に、どの共変量をモデルに入れるかである。第三に、アウトカムの平均をどのように変換して共変量と結びつけるかである。この変換をリンク関数といい、確率や発生率のモデル化をより自然に行うことができる。
Rでは、glm関数を用いて一般化線型モデルを当てはめることができる。

glm(アウトカム ~ 共変量, family = 確率分布(link = リンク関数), data = データ名)

このコードのうちformulaはモデル式を入力するパーツであり、左辺と右辺には、それぞれアウトカムと共変量を指定する。また、familyとlinkを通じて、データの型にあった確率分布とリンク関数を選択する。たとえばfamily = binomial(link= "logit")というコードにより、ロジスティック回帰が実行される。

打ち切り　censoring
生存時間データを測定するとき、ある特定の時点で観測が妨げられ、その時点以降に関心のあるイベントが発生したであろうことしかわからなくなること。

回帰モデル　regression model
ある変数が他の変数とどのような関連にあるのかを調べるための統計手法。回帰分析と同義だが、「分析」は統計手法を指すニュアンスがあるのに対して、「モデル」というとなんらかの数式や確率分布を意味することが多い。

確率モデル　probability model
抽象的なデータの見方を「モデル」と本書では呼んでいる。確率モデルは、観測されたデータがどう生じるかを、確率分布を使って記述するモデルのこと。

片側p値　one-sided p-value
相関には正の相関と負の相関、因果効果には利益と害というように方向性がある。どちらかの方向性にしか関心がないとき用いられるp値のこと。片側ではなく両側p値を用いることが一般的。

Kaplan-Meier法　Kaplan-Meier method
生存時間解析において、生存曲線を推定する方法。途中で生存時間の観測が打ち切られなければ、単なる割合に一致する。打ち切りがある場合、打ち切り時点まではリスク集合に含め、打ち切り時点以降は分母から外して、生存確率を段階的に推定する。

競合リスク　competing risk
がんの原病死を追跡するときの事故死のように、それが起こると関心のあるイベントが観測されなくなる、競合するイベントのこと。

寄与割合　attributable fraction

効果サイズ　effect size
治療の効果の大きさや、治療を比較したときの差のこと。サンプルサイズ設計では、効果サイズの値を設定しなければならないが、そもそもそれを知りたいから研究をするのだから悩ましい。このジレンマを皮肉って、「サンプルサイズから逆算して出した集積可能な差のこと」といった人もいる。

交絡　confounding
曝露や治療とアウトカムの両方に関係する因子によって、効果の推定にバイアスが入ること。

Cox回帰　Cox regression
1972年にCox教授が発明し、大流行した統計手法。回帰モデルの一種だが、一般化線型モデルではない。生存時間をアウトカムとして扱い、生存曲線の差をハザード比として要約したり、様々な因子が生存時間と関連があるかどうか検討するために利用される。

サンプルサイズ設計　sample size calculation
対象者数などの研究の規模を決めること。たとえば、効果サイズ、αエラー、βエラー（または検出力）を設定することで、研究に必要な対象者数を計算できる。

情報バイアス　information bias
情報を集めるとき気をつけるべきバイアス。
信頼区間　confidence interval
推定値の精度を表す区間。95%信頼区間でいえば、仮想的反復を行い、毎回95%信頼区間を作ったとき、「真の値を含む区間」の割合が0.95になるように設計された指標のこと。

推定目標（エスティマンド）　estimand
研究で「なにを推定したいのか」を明確にしたもの。本文で繰り返し述べた「どの集団について、なにとなにを比べ、どの時点のなにを見るのか」という問いを、統計的に定義した対象と考えるとよい。臨床試験では、治療開始後の中止や追加治療などによって治療効果の意味があいまいになるため、計画段階で推定目標を決めておくことがICH E9ガイドラインで求められている。

生物統計家　biostatistician
医学・生命科学における統計専門家のことだが、バイオインフォマティシャン、データサイエンティスト、疫学者とは、所属学会やコミュニティが異なる。狭い意味では、臨床試験を専門とする統計プロフェッショナルのことを指し、そのための資格（試験統計家認定制度）もあるくらいだが、生物（bio）という接頭辞がついているためわかりにくい。

生存曲線　survival curve
ある時点までイベントを起こさずにいる確率を、時間に沿って示した曲線。がんや循環器疾患など多くの疾患領域で、研究結果が生存曲線として示されることが多い。

選択バイアス　selection bias
研究の対象となる集団を選ぶとき気をつけるべきバイアス。

DAG（有向非循環グラフ）　directed acyclic graph
抽象的なデータの見方を「モデル」と本書では呼んでいる。DAGは、変数間の因果関係を矢印で表した構造的な因果モデルの一種。

直接多項回帰　direct polytomous regression
競合リスクがある状況で、ある時点までにどのイベントが起きたかを分類データとして扱い、特定時点の累積発生確率を比較するための回帰モデル。本書では詳細には扱わないが、競合リスクを単なる打ち切りとして扱わず、複数のアウトカムとして記述する考え方と関係している。

デザイン　design
統計学では昔から実験計画のことを”design”と呼んできたが、それが転じて、研究立案やその際に決めるべき要素を意味するようになった。ランダム化臨床試験、調査、コホート研究などは、デザインの一種。

バイアス　bias
一般的には偏った見方や行動を指す言葉だが、統計学では、誤差をランダム誤差とバイアスに大別する。バイアスは、推定値が真値からずれる傾向やその程度の意味で用いられる。たとえるなら、ランダム誤差は的の中心を狙って矢を放つときのばらつき、バイアスは狙いが中心からずれている状態といえる。データを集めた後にバイアスがあることがわかったとしても、対処は難しい。


ハザード比　hazard ratio 
Cox回帰から計算される指標で、イベントが生じる速さを群間で比較するために用いられる。本文では、生存曲線が下がるスピードを比べる数字として説明した。

比　ratio
ある量を別の量で割ることで求められる指標。割合と率は比の一種。

比例ハザード性　proportional hazards assumption
死亡や増悪のようなイベントが生じるスピードが、群の間で定数倍になっていて、その関係が時間を通じて変わらないという仮定のこと。

p値　p-value
研究結果をみるとき、真っ先に見てしまいがちな数字。「帰無仮説の下で、観察された結果と同じか、それより極端な結果が得られる確率」と定義される。統計学的有意（statistical significance）、つまり誤差を越えた関連があるか見分けるときに用いられる。

Fine-Grayモデル　Fine-Gray model
1999年にFine教授とGray教授が発明した、Cox回帰を拡張した統計手法。競合リスクを含む生存時間データがアウトカムのときの回帰モデルの一種。

Fisher正確検定　Fisher’s exact test
2つの分類データに関連があるかどうかを調べるための仮説検定。「正確」と呼ばれるのは、大標本近似ではなく、表の実現確率を直接計算することからきている。つまり、「2つの分類データに関連がない」という帰無仮説の下で、観測された表と同じか、それよりも極端な表が得られる確率を、p値として計算する。ミルクティーの実験もその例。

βエラー　beta error
サンプルサイズ設計の鍵になる数字。せっかく臨床試験を行ったのに、真に効く治療を有効性がないと判断してしまう確率のこと。データをたくさん集めることができ、βエラーが低いことを、「検出力が高い」という。

ランダム化　randomization
新規治療と標準治療のように、介入の効果を比べたいとき、どの介入を受けるかをランダム（無作為）に決める操作のこと。バイアスが生じないようにする工夫のひとつ。

率（発生率、罹患率）　rate
一定時間に事象が生じるスピードを表す指標。疫学では、人年法（発生数/観察人年）で計算される。人数を人数×年で割っているため、単位は1/年（より一般には1/時間）。

リスク　risk
疾患が一定期間内に生じる確率のこと。リスクの値は、どの集団を対象に、どの時点までを見たかによって変わる。そのため、リスクを読むときは、対象集団と時間をあわせて確認する必要がある。

両側p値　two-sided p-value
相関には正の相関と負の相関、因果効果には利益と害というように方向性がある。両方の方向に関心があるとき用いられるp値のこと。片側ではなく両側p値を用いることが一般的。

Rubin因果モデル　Rubin causal model
抽象的なデータの見方を「モデル」と本書では呼んでいる。Rubin因果モデルは、同じ解析単位において原因が別の値をとっていたとき、アウトカムがどうなっていたか（潜在結果変数）を用いて、因果効果を定義したモデルのこと（田中2022、要引用）。割付アルゴリズムや確率分布を含めた枠組みを指すこともあるが、因果効果の定義に関わる部分に焦点を当てるため、それらは明示的には扱わない。

ロジスティック回帰　logistic regression
ある事象が生じる確率と、他の変数との関連を調べるための統計手法。2値データがアウトカムのときの回帰モデルの一種で、ロジットリンクを用いる点に特徴がある。回帰係数の指数（exponential）をとることでオッズ比を計算できる。

割合　proportion
全体に対してそれが占める分量を表す指標。2値データや分類データを要約するために用いられる。人数を人数で割っているため、単位がキャンセルして単位を持たない（無単位）。

あとがき
この本では、統計と数字、そして言葉に注目してきました。統計的な数値の意味は、データと確率モデルだけでは決まりません。研究者の問いからスタートして、研究デザイン、データ収集、解析、解釈を通じて、少しずつ定められ、洗練されていくものです。そして、その数字をなんの答えとして差し出すのかという責任もまた、研究者にあります。
もちろん少し角度を変えれば、別の物語も見えてくるはずです。たとえば、がんの手術を受けた患者さんの実態や課題が論文として報告されると、それが今後の研究や診療にどうつながっていくのか。結局、ロジスティック回帰の変数は、どのような手順で選ばれたのか。あるいはもっと素朴に、この後、赤穂の牡蠣を食べることができたのか、と気にしていただいてもかまいません。研究は、物語に溢れています。
今も、夜遅くまで論文を書いている研究者や大学院生がいることでしょう。その姿の輪郭を少しでも書き記すことができていたなら、著者としてはそれだけでうれしいです。
